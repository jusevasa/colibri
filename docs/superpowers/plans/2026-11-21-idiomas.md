# Idiomas (español e inglés) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** La interfaz de Colibrí sale en el idioma del sistema: inglés si es inglés, español en cualquier otro caso.

**Architecture:** `src/i18n/` con un `struct Texts` formado por un sub-struct por zona de la interfaz (`menu`, `overlay`, `chrome`, `agents`, `term`), cada uno en su archivo con sus constantes `ES` y `EN`. `i18n::t()` devuelve los del idioma elegido al arrancar (`OnceLock`). Un texto que falte en un idioma no compila.

**Tech Stack:** Rust 2024, objc2-foundation (`NSUserDefaults` `AppleLanguages`), egui.

**Spec:** `docs/superpowers/specs/2026-11-21-idiomas-design.md`

## Global Constraints

- Los textos de `ES` son exactamente los de hoy (la versión en español no cambia ni un píxel).
- Inglés al estilo macOS: Title Case en menús («New Tab», «Reopen Closed Tab»), frase normal en el resto.
- No se traducen: código, comentarios, commits, stderr de depuración, textos que vienen de fuera (títulos de programas, carpetas, ramas, salida de comandos).
- Sin dependencias nuevas.
- `COLIBRI_LANG=es|en` fuerza el idioma.
- Desviación de la spec (decisión mía): en vez de un solo `src/i18n.rs`, una carpeta `src/i18n/` con un archivo por zona, porque son ~300 textos; sigue siendo un solo sitio para traducir.

## Review Focus

- Textos con datos (plurales, «hace N min», «N agentes») en inglés: singular/plural correctos («1 agent», «2 agents»).
- Anchos fijos pensados para el español (botones, columnas de Puertos/Procesos, filtros del panel): el inglés no debe cortarse ni solaparse.
- El menú «Ventana»/«Window» sigue siendo el menú de ventanas de macOS en los dos idiomas.
- El guion `menu <título>` sigue funcionando con los títulos en español (guiones existentes).
- Atajos y búsqueda de la paleta: buscar por el texto del idioma activo.

### Task 1: Infraestructura

**Files:** Create `src/i18n/mod.rs` y `src/i18n/{menu,overlay,chrome,agents,term}.rs` (vacíos); modify `src/main.rs` (`mod i18n;`, `i18n::init()` al principio de `main`), `src/menu.rs` (`Menu.windows: bool` en vez de comparar con «Ventana»), `scripts/bundle.sh` (`CFBundleDevelopmentRegion`, `CFBundleLocalizations`, `es.lproj`/`en.lproj` con `ServicesMenu.strings`).

**Interfaces (produces):** `i18n::Lang { Es, En }`, `i18n::init()`, `i18n::lang() -> Lang`, `i18n::t() -> &'static Texts`, `i18n::texts(Lang) -> &'static Texts`, `Texts { menu: menu::T, overlay: overlay::T, chrome: chrome::T, agents: agents::T, term: term::T }`. Cada zona: `pub struct T { … }`, `pub const ES: T`, `pub const EN: T`. Textos con datos: campos `fn(…) -> String` apuntando a funciones con nombre.

- [ ] Prueba `elige_idioma`: `pick("en-US") == En`, `pick("en") == En`, `pick("es-CO") == Es`, `pick("fr-FR") == Es`, `pick("") == Es`.
- [ ] Implementar; `cargo test elige_idioma` pasa; `cargo build` sin avisos nuevos.

### Task 2: Barra de menús (zona `menu`)

Títulos de menús y entradas de `App::menu_spec` (`main.rs`) y lo que `menu.rs` ponga visible (Servicios, Ocultar, Salir…).

- [ ] Mover textos a `i18n/menu.rs`; `menu_spec` usa `t().menu`.
- [ ] Guion: `menu Nueva ventana` sigue funcionando; con `COLIBRI_LANG=en`, `menu New Window`.

### Task 3: Paleta, Preferencias y overlays (zona `overlay`)

Todo `overlay.rs`: paleta, `PREF_ROWS` y sus valores, renombrar, historial (`ago`), selectores de ramas y carpetas, sugerencias.

- [ ] Mover textos; `ago` de `overlay.rs` en las dos lenguas.
- [ ] Prueba `hace_tiempo_en_los_dos_idiomas` con `texts(Lang::En)` y `texts(Lang::Es)`: 30 s → «just now»/«ahora», 120 s → «2 min ago»/«hace 2 min» (lo que diga el texto actual en ES).

### Task 4: Cromo (zona `chrome`)

`main.rs` salvo el menú: barra de pestañas, «Actualizar», Puertos y Procesos, detener procesos, notificaciones, `ago` de `main.rs`, nombres por defecto de pestaña; y `notify.rs`, `shell.rs`, `procs.rs` si tienen textos visibles.

- [ ] Mover textos; plural correcto en inglés.

### Task 5: Panel de agentes y terminal (zonas `agents` y `term`)

`agents.rs` (filtros, estados, buscador, vacíos, «Nueva sesión»), `view.rs` y `session.rs` (estados del agente, sugerencia «↵ ejecutar · → escribir», código y duración de comandos que fallan, cajas), `history.rs`, `complete.rs`, `claude.rs` si tienen textos visibles.

- [ ] Mover textos; las pruebas que comparan textos usan `texts(Lang::Es)`.

### Task 6: Comprobación

- [ ] Captura del guion en español antes del cambio (desde el commit actual) y después, con `COLIBRI_LANG=es`: idénticas byte a byte.
- [ ] Capturas con `COLIBRI_LANG=en` de pestañas + panel de agentes, paleta, Preferencias, Puertos, Procesos, historial y selector de carpetas: nada en español, nada cortado.
- [ ] `grep` de literales con letras fuera de `src/i18n/`, comentarios y stderr: ninguno visible.
- [ ] `cargo test`, `cargo clippy` sin avisos nuevos; actualizar `CLAUDE.md` (sección de arquitectura + «Una acción nueva» / «Una preferencia nueva» mencionan añadir el texto en `i18n`).
